# 红楼梦本体知识库设计说明

> 依据《红楼梦》第二回《冷子兴演说荣国府》构建，本体文件见 `hongloumeng.owl`（OWL/RDF-XML 格式）。

## 一、类（Class）设计

本体共定义 **7 个类**，分属三条主线：

| 类 | 父类 | 说明 |
|----|------|------|
| 人物 | （顶层） | 所有登场人物的抽象 |
| 贾府人物 | 人物 | 贾氏宗族成员 |
| 荣国府人物 | 贾府人物 | 荣国府一房 |
| 宁国府人物 | 贾府人物 | 宁国府一房 |
| 外人 | 人物 | 贾府以外的人（冷子兴、贾雨村） |
| 府第 | （顶层） | 府邸（荣国府、宁国府） |
| 官职 | （顶层） | 官衔/封号（员外郎、贵妃） |

**设计思路**：用"人物"作为顶层类，按"是否贾府"、"荣/宁两房"逐层细分，形成清晰的三级类层次，体现"子类继承父类"的语义；"府第"和"官职"作为独立顶层类，用于作为对象属性"居住于""任职于"的值域。

## 二、属性（Property）设计

### 对象属性（Object Properties，共 9 个）

| 对象属性 | 定义域 | 值域 | 说明 |
|----------|--------|------|------|
| 是父亲 | 人物 | 人物 | 父子关系 |
| 是母亲 | 人物 | 人物 | 母子/母女关系 |
| 是丈夫 | 人物 | 人物 | 夫妻关系（与"是妻子"互逆） |
| 是妻子 | 人物 | 人物 | 夫妻关系（与"是丈夫"互逆） |
| 是儿子 | 人物 | 人物 | 子关系 |
| 是女儿 | 人物 | 人物 | 女关系 |
| 是外孙女 | 人物 | 人物 | 祖孙关系（林黛玉—贾母） |
| 居住于 | 人物 | 府第 | 人物与府第的归属关系 |
| 任职于 | 人物 | 官职 | 人物与官职的任职关系 |

其中 `是丈夫 ↔ 是妻子` 通过 `owl:inverseOf` 声明为**互逆属性**，演示了 OWL 属性公理。

### 数据属性（Data Properties，共 2 个）

| 数据属性 | 值域 | 用途 |
|----------|------|------|
| 别称 | xsd:string | 人物的别名（史太君、宝玉、凤辣子） |
| 说明 | xsd:string | 人物的简要说明 |

## 三、关系设计（关键人物关系如何表达）

以《冷子兴演说荣国府》原文为依据，核心关系用对象属性三元组表达：

- **夫妻关系**：`贾政 —是丈夫→ 王夫人`；`王夫人 —是妻子→ 贾政`（互逆）。
- **父子关系**：`贾政 —是父亲→ 贾珠 / 贾元春 / 贾宝玉 / 贾探春`；`贾赦 —是父亲→ 贾琏 / 贾迎春`；`贾敬 —是父亲→ 贾珍 / 贾惜春`。
- **母子关系**：`贾母 —是母亲→ 贾赦 / 贾政`；`王夫人 —是母亲→ 贾珠 / 贾元春 / 贾宝玉`。
- **祖孙关系**：`林黛玉 —是外孙女→ 贾母`。
- **归属关系**：`贾赦 / 贾政 / 贾宝玉 / 林黛玉 / 贾惜春 —居住于→ 荣国府`。
- **任职关系**：`贾元春 —任职于→ 贵妃`。

## 四、实例（Individual）说明

共定义 **25 个个体**，按类分布如下：

- **荣国府人物（14 个）**：贾母、贾赦、邢夫人、贾政、王夫人、贾珠、李纨、贾元春、贾宝玉、贾探春、贾迎春、贾琏、王熙凤、林黛玉。
- **宁国府人物（5 个）**：贾敬、贾珍、贾蓉、秦可卿、贾惜春。
- **外人（2 个）**：冷子兴、贾雨村。
- **府第（2 个）**：荣国府、宁国府。
- **官职（2 个）**：员外郎、贵妃。

每个个体都声明了 `rdf:type`（所属类），并携带了相应的对象属性断言和数据属性（别称/说明）。例如：

```
贾宝玉  rdf:type  荣国府人物
        是儿子    贾政 / 王夫人
        居住于   荣国府
        别称     "宝玉"
```

## 五、设计说明总结

本本体以"类层次（人物→贾府人物→荣/宁国府人物）"为骨架，以"是父亲/是母亲/是丈夫/是妻子/居住于/任职于"等对象属性刻画人物之间的亲属与归属关系，以"别称/说明"数据属性补充字面信息，共 25 个个体、184 条三元组，完整再现了《冷子兴演说荣国府》中荣宁二府的核心人物谱系。该本体可在 Protege 中用 OntoGraf 可视化展示，并可由推理机进行属性逆推等推理。
