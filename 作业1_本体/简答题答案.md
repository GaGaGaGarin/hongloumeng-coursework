# 作业1 简答题答案（40 分）

## 1. 下载并安装 Protege 本体构建工具

已完成：下载 `Protege-5.2.0-win`，解压到 D 盘 `D:\【Protege-5.2.0-win`，运行其中的 `run.bat` 启动。Protege 是斯坦福大学开发的免费开源本体编辑工具，支持 OWL 2 标准，可用于构建、编辑和可视化本体。

## 2. 学习 Protege 中的核心概念

### （1）什么是 Class、Object properties、Data properties

三者是 OWL 本体的三大支柱，共同描述一个领域的知识结构：

- **Class（类）**：对事物进行抽象归类，表示"概念的集合"。例如"人物""府第""官职"都是类；类之间可以构成层级（subClassOf），如"荣国府人物"是"贾府人物"的子类，"贾府人物"是"人物"的子类。
- **Object property（对象属性）**：描述**两个个体（实例）之间**的语义关系。例如"是父亲""是妻子""居住于"。它有定义域（domain）和值域（range），本作业中都限定在"人物"（或"府第"）上。
- **Data property（数据属性）**：描述**个体与具体数据值**（字符串、数字等字面量）之间的关系。例如"别称"（史太君、宝玉）、"说明"。它的值域是数据类型（xsd:string 等），而非个体。

一句话区别：Class 回答"是什么"，Object property 回答"和其他个体什么关系"，Data property 回答"有什么字面属性"。

### （2）什么是 Individual、如何给 Individual 添加属性和关系

- **Individual（个体/实例）**：是类的具体实例，代表某个具体对象。例如"贾宝玉""王熙凤"是"荣国府人物"类的个体，"荣国府"是"府第"类的个体。
- **添加属性和关系**：在 Protege 的 `Individuals` 标签页选中某个个体，右侧的 **Object property assertions** 面板点击 `+`，选择对象属性并填写目标个体，即可添加一条关系断言（如：贾宝玉 → "是儿子" → 贾政）；在 **Data property assertions** 面板点击 `+`，选择数据属性并填写字面值，即可添加数据属性断言（如：贾宝玉 → "别称" → "宝玉"）。

### （3）结合上述学习，谈谈你对本体知识库结构的理解

本体知识库可以概括为 **"类层次 + 属性约束 + 个体事实 + 推理"** 四层结构：

1. **类层次（Taxonomy）**：用类和子类关系（subClassOf）组织概念的层级分类，构成知识库的"骨架"。
2. **属性约束（Property）**：对象属性定义个体间的语义关系，数据属性定义个体与字面量的关系，属性上的 domain/range 和 inverseOf 等公理进一步约束了知识的合法性。
3. **个体事实（Individuals）**：具体对象及其类型和属性断言，构成知识库的"血肉"，是实际的知识实例。
4. **推理（Reasoner）**：在显式声明的基础上，推理机可自动推导出隐含的知识（如由"贾政 是父亲 贾宝玉"和"是父亲 的逆是 是儿子"推出"贾宝玉 是儿子 贾政"）。

以本作业的《红楼梦》本体为例：顶层"人物"类分出"贾府人物"和"外人"，"贾府人物"再分"荣国府/宁国府人物"；对象属性"是父亲/是母亲/是丈夫/是妻子"等刻画人物关系；个体"贾宝玉""林黛玉"等携带这些关系断言；于是原本零散的人物关系被组织成一张机器可读、可推理、可查询的语义网络。这正是本体相对于普通表格/文档的优势——它把知识结构化了。
